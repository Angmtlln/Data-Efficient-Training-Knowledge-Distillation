# По словам: отрицания

**Результат: 86.47% верных ответов, разброс 2.65 п.п.**

Все отрицательные отзывы в выбранном наборе содержат маркер отрицания. Это создает слишком простую подсказку для модели. Результат хуже контроля на 6.54 п.п.

## Идея и реализация

Больше примеров нужного языкового явления может помочь модели лучше с ним работать.

В первую очередь брала строки со словами not, never, no и n't. Остальные места заполняла случайно.

## Метрики и сравнение

Сравнение: **случайный отбор для языковых групп**. Разница средней точности: **-6.54 п.п.**.

| Показатель | Среднее, % |
|---|---|
| Верных ответов (accuracy) | 86.47 |
| F1, среднее двух классов | 86.24 |
| F1 положительного класса | 87.96 |
| Верных на фразах с отрицанием, 164 строки | 90.04 |
| Верных на фразах с противопоставлением, 121 строка | 88.15 |

## Сравнение со статьями

Отдельные проверки языковых явлений находили ошибки даже у сильных моделей. В одном исследовании участники с CheckList нашли почти втрое больше ошибок, чем участники без него.

CheckList посвящен проверке моделей. Мой способ отбора — собственная простая проверка этой идеи.

- [CheckList: проверка отдельных языковых умений](https://arxiv.org/abs/2005.04118).

Полные названия и проверенные места статей — в [списке источников](../../docs/SOURCES.md).

## Вывод

Не повторять жесткий отбор только по маркерам; при новых опытах оставлять обычные фразы.

Вывод основан на трех запусках. При одновременном изменении нескольких условий оценивается их совместный эффект.
