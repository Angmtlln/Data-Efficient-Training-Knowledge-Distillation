# По сходству текстов: противопоставления

**Результат: 92.01% верных ответов, разброс 0.07 п.п.**

На фразах с противопоставлением +1.10 п.п., но на всем тесте -0.99 п.п. Улучшение одной небольшой группы не компенсировало общее снижение.

## Идея и реализация

Текст может быть полезен для нужного явления даже без конкретного ключевого слова.

MiniLM превращает фразы в числовые представления. Выбрала тексты, близкие к среднему представлению целевых примеров.

## Метрики и сравнение

Сравнение: **случайный отбор для языковых групп**. Разница средней точности: **-0.99 п.п.**.

| Показатель | Среднее, % |
|---|---|
| Верных ответов (accuracy) | 92.01 |
| F1, среднее двух классов | 92.01 |
| F1 положительного класса | 92.00 |
| Верных на фразах с отрицанием, 164 строки | 90.65 |
| Верных на фразах с противопоставлением, 121 строка | 92.01 |

## Сравнение со статьями

Авторы получили представления предложений, которые позволяют быстро искать похожие по смыслу тексты. Это работа о представлении и сравнении текстов, а не доказательство пользы отбора 10% SST-2.

Я использовала готовую модель all-MiniLM-L6-v2 из Sentence Transformers и выбирала тексты, близкие к выбранным примерам. Среднее сходство как правило отбора — мое упрощение, а не метод, проверенный в этой статье. Как и в CheckList, мне интересны отдельные языковые явления, но мои группы по словам пока не заменяют специальные тесты.

- [Sentence-BERT: сравнение смысла предложений](https://arxiv.org/abs/1908.10084).
- [CheckList: проверка отдельных языковых умений](https://arxiv.org/abs/2005.04118).
