# Пары с замененным участником

**Результат: 92.89% верных ответов, разброс 0.34 п.п.**

Разница с целыми парами практически нулевая и меняет знак между запусками. При этой дозе преимущество целых пар не обнаружено.

## Идея и реализация

Если помогает именно связь двух фраз, замена одной из них должна ухудшить результат.

В каждой паре заменила один текст другим с той же меткой и близкой длиной. 6502 строки из 6534 остались общими с парным набором.

## Метрики и сравнение

Сравнение: **случайный отбор для опыта с парами**. Разница средней точности: **-0.08 п.п.**.

| Показатель | Среднее, % |
|---|---|
| Верных ответов (accuracy) | 92.89 |
| F1, среднее двух классов | 92.89 |
| F1 положительного класса | 92.98 |
| Верных на фразах с отрицанием, 164 строки | 90.04 |
| Верных на фразах с противопоставлением, 121 строка | 91.46 |

## Сравнение со статьями

Люди меняли отзывы IMDb и предложения SNLI так, чтобы менялся правильный ответ, а лишних правок было мало. Обучение на исходных и измененных текстах вместе помогало лучше работать на обоих видах данных.

Сопоставление длины и замена одного участника пары — мои контрольные условия. В статье проверяли сочетание исходных и измененных людьми текстов.

- [Kaushik и соавторы: пары с измененным смыслом](https://arxiv.org/abs/1909.12434).

Полные названия и проверенные места статей — в [списке источников](../../docs/SOURCES.md).

## Вывод

Сохранять эту проверку при продолжении парного опыта.

Вывод основан на трех запусках. При одновременном изменении нескольких условий оценивается их совместный эффект.
