# Случайный отбор для языковых групп

**Результат: 93.00% верных ответов, разброс 0.46 п.п.**

Это контроль для всех способов отбора по отрицаниям и противопоставлениям во второй серии.

## Идея и реализация

Чтобы сравнение было честным, случайный вариант должен выбирать из тех же доступных строк.

Исключила 4096 строк, на которых обучала маленькую модель, и 512 строк для целевых примеров. Из оставшихся выбрала случайный поднабор.

## Метрики и сравнение

Это контрольный вариант: с ним сравниваются другие способы отбора в той же группе.

| Показатель | Среднее, % |
|---|---|
| Верных ответов (accuracy) | 93.00 |
| F1, среднее двух классов | 93.00 |
| F1 положительного класса | 93.17 |
| Верных на фразах с отрицанием, 164 строки | 91.06 |
| Верных на фразах с противопоставлением, 121 строка | 90.91 |

## Сравнение со статьями

Это необходимое сравнение, а не метод из отдельной статьи.

В моих опытах контроль повторяет ограничения своего семейства. Сравнивать с чужой случайной выборкой из другой серии нельзя.

Отдельной статьи-источника нет: это мое условие для честного сравнения.

Полные названия и проверенные места статей — в [списке источников](../../docs/SOURCES.md).
