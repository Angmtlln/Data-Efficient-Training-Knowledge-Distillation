# Без нестабильных примеров

**Результат: 91.86% верных ответов, разброс 0.41 п.п.**

91.86% — ниже обычного случайного варианта. Это специально ограниченный набор.

## Идея и реализация

Нужно проверить, что меняется, если убрать нестабильные строки совсем.

Для 932 нестабильных строк нашла замены с той же меткой и близкой длиной. Остальные 5602 строки общие с вариантами, где нестабильные примеры добавляются.

## Метрики и сравнение

Это контрольный вариант: с ним сравниваются другие способы отбора в той же группе. Относительно обычной случайной выборки: **-0.88 п.п.** Это другое сравнение.

| Показатель | Среднее, % |
|---|---|
| Верных ответов (accuracy) | 91.86 |
| F1, среднее двух классов | 91.85 |
| F1 положительного класса | 92.15 |
| Верных на фразах с отрицанием, 164 строки | 89.02 |
| Верных на фразах с противопоставлением, 121 строка | 87.60 |

## Сравнение со статьями

На CIFAR-10 авторы убирали до 30% обучающих примеров без заметного ухудшения качества. Они в первую очередь убирали примеры, которые модель не забывала.

Контроль с полным исключением нестабильных строк я придумала для своей проверки дозы.

- [Toneva и соавторы: забывание примеров](https://arxiv.org/abs/1812.05159).

Полные названия и проверенные места статей — в [списке источников](../../docs/SOURCES.md).

## Вывод

Использовать для оценки эффекта добавки, но не как единственный ориентир качества.

Вывод основан на трех запусках. При одновременном изменении нескольких условий оценивается их совместный эффект.

| 202 | 92.32 | 92.31 | 89.63 | 90.91 |

| 404 | 91.74 | 91.74 | 88.41 | 87.60 |

Разброс в начале карточки — стандартное отклонение. Различных наборов текстов: 3. Если набор один, между запусками менялось только обучение. Группы отрицаний и противопоставлений выделены по словам, без независимой проверки смысла.
