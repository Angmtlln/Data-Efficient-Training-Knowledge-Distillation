# По словам: противопоставления

**Результат: 92.81% верных ответов, разброс 0.18 п.п.**

Общая точность немного ниже контроля: -0.19 п.п. Большая доля слов противопоставления сама по себе не дала выигрыша.

## Идея и реализация

Больше примеров нужного языкового явления может помочь модели лучше с ним работать.

В первую очередь брала строки со словами but, although, however и yet. Остальные места заполняла случайно.

## Метрики и сравнение

Сравнение: **случайный отбор для языковых групп**. Разница средней точности: **-0.19 п.п.**.

| Показатель | Среднее, % |
|---|---|
| Верных ответов (accuracy) | 92.81 |
| F1, среднее двух классов | 92.81 |
| F1 положительного класса | 92.92 |
| Верных на фразах с отрицанием, 164 строки | 89.43 |
| Верных на фразах с противопоставлением, 121 строка | 91.18 |

## Сравнение со статьями

Отдельные проверки языковых явлений находили ошибки даже у сильных моделей. В одном исследовании участники с CheckList нашли почти втрое больше ошибок, чем участники без него.

CheckList посвящен проверке моделей, а не отбору обучения по словам not или but. Мой способ отбора — собственная простая проверка этой идеи.

- [CheckList: проверка отдельных языковых умений](https://arxiv.org/abs/2005.04118).

Полные названия и проверенные места статей — в [списке источников](../../docs/SOURCES.md).
