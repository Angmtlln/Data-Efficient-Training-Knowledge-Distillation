# Случайный набор с заданным составом

**Результат: 92.89% верных ответов, разброс 1.00 п.п.**

92.89% — контроль для четырех мягких вариантов третьей серии.

## Идея и реализация

Нужно сравнить способы отбора без перекоса по метке, длине и трудности для маленькой модели.

Задала одинаковое число строк в группах по метке, длине, правильности ответа маленькой модели и величине ее ошибки. Затем выбрала строки случайно.
