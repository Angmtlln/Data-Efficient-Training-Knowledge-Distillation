# Сохраненные результаты

Начните с [общего отчета](../REPORT.md). Здесь лежат результаты всех 84 обучений, включая неудачные методы.

- `raw/` — метрики, ответы моделей, настройки и окружение. Порядок ответов совпадает с порядком строк закрепленной версии SST-2 test.
- `analysis/` — таблицы и графики по всем сериям.
- `methods/` — 28 карточек: идея, результат, вывод и сравнение со статьей.
- `selections/` — какие строки выбрали для каждого опыта.
- `inputs/` и `preparation/` — оценки и проверки, сделанные до обучения.
- `executed_code/` — снимки использованного кода. Старые пути в результатах оставлены для истории; подключаться по ним не нужно.
- `history/` — краткое описание первых 54 запусков. Текущие выводы учитывают и следующую серию.
- `pairs_v2_candidates/` — новые, еще не проверенные пары. В обучение они не входили.

Проверить целостность: `python scripts/artifacts.py verify` из корня проекта.

Большие кеши и исходные тексты скачиваются кодом. Веса обученных моделей не сохранены; ответы моделей и метрики сохранены полностью.
