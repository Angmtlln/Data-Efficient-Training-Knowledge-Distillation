# Протокол, зафиксированный до GPU-обучения

## Предпосылка

В отчете Амира отбор целых предложений дал 94.62% на GLUE validation, full — 95.57%. Катя добавила контрастные подфразы к целым предложениям и получила небольшой положительный сигнал на двух завершенных парных сравнениях. Эти результаты мотивируют опыт; контроль здесь обучается заново.

- Amir: https://github.com/Angmtlln/Data-Efficient-Training-Knowledge-Distillation/blob/Amir_N_experiments/REPORT.md
- Katya: https://github.com/Angmtlln/Data-Efficient-Training-Knowledge-Distillation/blob/katyaSVP/SVP_RESULTS.md
- Исходные деревья: Socher et al., 2013, https://aclanthology.org/D13-1170/

Моя гипотеза: небольшая добавка контрастных подфраз полезнее, если модель явно учится различать тональность части и целого. Функция ошибки ниже — предлагаемая адаптация для этого опыта.

## Данные и отбор

Модель ModernBERT-base, закрепленная ревизия в config.json. Pool 65349, внутренняя val 2000, итоговая оценка GLUE validation 872. Сохраняется исходное разбиение проекта и его хеши.

Используются только train-деревья SST. Нейтральные узлы исключены, метки 0/1 соответствуют отрицательному классу, 3/4 — положительному. Узел допускается только при совпадении нормализованного текста и бинарной метки с pool. Точные нормализованные совпадения с val/test исключены из кандидатов; метки val/test не участвуют в отборе. При дублирующемся тексте берется минимальный pool index.

Для пары: целое предложение и его настоящий потомок в дереве; метки противоположны; потомок содержит >=8 слов и >=50% слов родителя; добавленный контекст содержит >=2 слов и маркер отрицания/противопоставления. Отброшены очевидные обрывы на союзах. Оба текста целиком помещаются в 64 токена ModernBERT. Один родитель и одна подфраза участвуют максимум в одной паре. При нескольких подходящих детях сначала рассматривается самый длинный. Затем применяется сохраненный текстовый просмотр ассистентом, без использования результатов обучения. Метки не исправляются.

После фильтров 166 пар, после просмотра 111. Запрошенная верхняя граница 131 уменьшена до доступных 111 до обучения. Все 111 включены в каждую экспериментальную выборку. Подготовлены seeds 1103/1201/1301. Каждая выборка содержит 6534 различных pool index. В контроле 6534 целых предложения. В смеси 111 заменяются подфразами с сохранением метки удаляемого примера; выбирается ближайшая доступная длина. Общий фон контроля и смеси — 6423 строки. Все три смеси внутри seed идентичны.

Внутренняя val состоит из фраз. Ее родство с другими train-фразами сохраняется в унаследованном разбиении; полное исключение родственных деревьев изменило бы постановку. Итоговый GLUE validation многократно изучался в проекте. Для подтверждения малых эффектов потребуется независимая оценка.

## Обучение

3 эпохи, 32 реальных текста в батче (последний — 6), 205 шагов за эпоху, 615 суммарно. lr=5e-5, warmup=6%, weight decay=.01, max_length=64. Лучшая эпоха выбирается по внутренней val accuracy. GPU bf16 при поддержке, иначе fp16. На одной серии все варианты идут в одном окружении.

Технически один элемент обучающего Dataset содержит готовый батч: per_device_train_batch_size=1 означает 32 текста. Поэтому внутренний счетчик samples/sec Trainer считает пакеты, а не тексты. Предварительно сформированные батчи фиксированы; Trainer перемешивает порядок батчей между эпохами. Такой порядок выбран для точного сравнения paired/rank; он одинаков для этих двух вариантов. Independent формирует батчи из одиночных строк. Повторов и дополнительного предъявления пар нет.

`mixed_rank` использует:

    loss = CE + 0.2 * mean_pairs(max(0, 0.2 - (p_positive(x_pos) - p_positive(x_neg))))

CE усредняется по всем текстам батча; дополнительная ошибка — по парам данного батча. При отсутствии пар она равна нулю. В paired варианте ее коэффициент равен нулю. Порядок пары определяется существующими метками. Коэффициент и отступ зафиксированы до результатов. Они не подбираются по GLUE validation.

## Сравнения

1. Основное: mixed_rank − mixed_paired — добавление парной ошибки при тех же текстах и батчах.
2. mixed_paired − mixed_independent — совместное предъявление.
3. mixed_independent − roots — замена части целых предложений.
4. mixed_rank − roots — полный эффект предлагаемого метода.

Показать каждый seed, средние accuracy/macro-F1 и SD, разницы в процентных пунктах, кривые обучения. Три seed дают предварительную оценку. Seed задает и обучение, и выборку. Статистически подтвержденный выигрыш заранее не предполагается.

Короткие пилоты по 20 шагов используют только внутреннюю val и проверяют исполнение. Их метрики хранятся отдельно от основных результатов.
