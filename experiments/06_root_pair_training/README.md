# Целое предложение и контрастная подфраза

Я проверяю, помогает ли явно обучать ModernBERT связи между целым предложением и его частью с противоположной тональностью.

**Завершены все 12 основных запусков: 4 варианта × 3 seed.** Лучший результат — 94.72%, +0.57 п.п. к контролю. [Отчет, графики и исходные результаты](../../results/root_pairs/REPORT.md).

| Вариант | Данные | Обучение |
|---|---|---|
| `roots` | 6534 целых предложения | Обычная классификация |
| `mixed_independent` | 6423 целых предложения + 111 подфраз | Случайные батчи |
| `mixed_paired` | Те же 6534 текста | Каждая пара в одном батче |
| `mixed_rank` | Те же тексты и батчи, что выше | Классификация + ошибка на порядок вероятностей |

Основное сравнение: `mixed_rank` против `mixed_paired`. Сравнение `mixed_rank` с `roots` показывает общий эффект изменения данных и обучения.

## Что уже готово

- Исходные деревья train SST: `inputs/sst_train.parquet`, источник и SHA-256 в `reports/source.json`.
- 6658 целых предложений сопоставлены с pool по нормализованному тексту и метке.
- Автоматические фильтры оставили 166 непересекающихся пар. После текстового просмотра ассистентом оставлены 111; решения и тексты — `pair_review.json`. Это один просмотр, без независимой человеческой разметки.
- 12 подвыборок: `selections/`. Баланс классов внутри каждого seed совпадает с контролем.
- Снимок SST-2, токенизатор и токенизированные данные находятся в локальной папке `data/`. В Git эта папка не включается; `setup.py` восстанавливает данные.
- CPU-тесты проверяют парсер, состав батчей, направление градиента и реальное обучение небольшой случайно инициализированной ModernBERT. Полный GPU-пилот выполняется перед основной серией.

Я сохранила 111 одинаковых пар во всех seed. Меняются остальные целые предложения, заменяемые строки, батчи и инициализация модели. Для каждой добавленной подфразы удаляется целое предложение того же класса с ближайшей длиной. Ее собственный родитель остается в обучении. Замены: `reports/replacements_s*.json`.

## Запуск на ВМ

Перенести **всю эту папку**, включая локальную `data/`, на ВМ. Работать из ее корня. Требуется примерно 25 ГБ свободного диска для весов, кеша и временных checkpoint.

1. Проверить `nvidia-smi`. Использовать установленный PyTorch, совместимый с GPU. Для RTX 50xx нужна CUDA-сборка PyTorch с поддержкой Blackwell.
2. Установить остальные зависимости и проверить пакет:

```bash
python -m pip install -r requirements.txt
python verify.py
python test_experiment.py
```

Если папка загружена из Git без данных:

```bash
python setup.py
python verify.py
python test_experiment.py
```

Запланированные запуски:

```bash
python run_queue.py --output outputs --local local_checkpoints --dry-run
```

Сначала пилоты обоих путей обучения по 20 шагов, оценка на внутренней val:

```bash
python run_queue.py --output outputs --local local_checkpoints --pilot-only
```

Основная очередь сама повторно проверяет завершение пилотов и пропускает готовые результаты:

```bash
python run_queue.py --output outputs --local local_checkpoints
```

На ВМ запускать через Supervisor; пример в `supervisor.conf.example`. Подставить абсолютные пути к этой папке и Python. Очередь ждет, пока GPU освободится, и не останавливает другие процессы. Для нескольких GPU или нескольких пользователей потребуется согласовать отдельное устройство; текущий запуск рассчитан на одну GPU.

## Восстановление и сохранение

Повторить ту же команду после обрыва. Сохраняются optimizer, scheduler, RNG и состояние Trainer; копии checkpoint проверяются по хешам. Одновременно запускать одну очередь с данным output. Код и настройки входят в идентификатор обучения: после их изменения создается новый запуск.

После завершения остаются лучшая модель, токенизатор, предсказания, история, версии библиотек, состав выборки и метрики. Промежуточные checkpoint удаляются после успешного сохранения результата.

Для локальной копии с компьютера, после подстановки выданных адреса, порта и пути:

```bash
rsync -az --exclude 'checkpoints/' --exclude 'local_checkpoints/' \
  -e 'ssh -i ~/.ssh/vast_ai -p PORT' \
  root@HOST:/workspace/06_root_pair_training/outputs/ ./outputs/
```

Веса тоже копируются. Команда не удаляет локальные файлы. На подключенной ВМ я настрою регулярное копирование в `itmo/ENN/HW-project`.

## Отчет

После каждого основного запуска очередь пересчитывает отчет. Вручную:

```bash
python analyze.py --output outputs
```

В `outputs/report/`: accuracy и macro-F1, результаты каждого seed, разницы между вариантами, история train loss и val accuracy, графики и `REPORT.md`. Пока серия не завершена, отчет показывает фактическое число запусков.

Подробности дизайна и формула ошибки — `PROTOCOL.md`.
