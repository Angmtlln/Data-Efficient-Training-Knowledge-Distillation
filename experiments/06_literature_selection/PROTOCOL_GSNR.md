# Дополнение: динамика линейного proxy по мотивам EMNLP 2026

Зафиксировано до расчёта скора и до запусков `long_gsnr`. Исследовательское сравнение с заранее определённым `long_random` серии 06. Цель — проверить, полезна ли среди длинных фраз доля примеров, которые proxy быстро и согласованно усваивает, без чистого отбора самых трудных и без нарушения квот классов.

Идея вдохновлена [Yuan et al., EMNLP 2026](https://aclanthology.org/2026.emnlp-main.2297/): относительное изменение нормы градиента и разногласие ансамбля. У нас proxy — TF-IDF + SGD logistic classifier, а не ансамбль LoRA и не градиенты генеративного LLM, применены OOF, квоты и общий случайный фон. Поэтому это `GSNR-inspired`, а не воспроизведение GRADFILTERING.

На том же очищенном пуле, что серия 06: те же 3 StratifiedGroupKFold (seed 20261122), внутри каждого fold 3 SGD-модели с разными seed 11/23/37 и общим TF-IDF словарём, построенным только по обучающим fold. На held-out fold записать вероятность корректной метки после 1-й и 8-й эпох. Для бинарного logistic loss и L2-нормализованного TF-IDF полный градиент по весам и свободному члену имеет норму `(1-p_gold) * sqrt(||x||² + 1)`; её считаем для каждой модели на каждой из двух точек. Использовать среднее ранней нормы `early`, среднее и дисперсию поздней нормы `late`, `var`, и score `((early - late)/(early + 0.001))/(var + 0.001)`. Единое значение epsilon здесь фиксировано заранее и является адаптацией, а не подобранным по качеству ModernBERT параметром.

Для seeds 17/42/101: фон и квоты целиком идентичны `long_random`; внутри каждой группы метки/длины из оставшихся выбрать по наибольшему score необходимое число примеров с seed-controlled разрешением ничьих. Ровно 6534 примера; те же гиперпараметры target, что в серии 06. Три дополнительных обучения. Главная метрика — парная разница accuracy на многократно использованной GLUE validation против `long_random` той же пары seed; macro F1 и состав выборок — дополнительные. Разница исследовательская, множественные сравнения, всего три повтора; метки всего допустимого пула доступны proxy.
