# Дополнительный тест на открытой исходной версии SST-2

Зафиксировано после старта обучения, но до оценки каких-либо моделей на этом наборе и до анализа итогов серии 07. Используем опубликованный файл `data/stsa.binary.test` из [зеркала AcademiaSinicaNLPLab](https://github.com/AcademiaSinicaNLPLab/sentiment_dataset/blob/master/data/stsa.binary.test), git blob `bb5d021fbc75d277a92c6a0fb1b0786984776007`. Это открытая версия SST binary test, а не официальная отправка предсказаний на GLUE leaderboard. Применяем к её тексту нормализацию `-lrb-`/`-rrb-` и экранированного слэша из оригинала в запись GLUE.

Аудит `audit_original_sst.py`: 1821 строка, 912 отрицательных и 909 положительных; проверочный открытый dev совпал с GLUE validation по тексту и метке 872/872, когда внесены те же исправления. После нормализации 1814 из 1821 текстов GLUE test совпадают с открытым test, семь имеют неэквивалентные записи (например, британский/американский вариант написания). Не приписываем семи несовпавшим точного соответствия и не утверждаем официальную сертификацию GLUE-метрик. Исходный тестовый файл и его хэш зафиксированы; никто из моделей на нём не обучается, но эти тексты и их разметка публичны, а возможное присутствие при предварительном обучении ModernBERT неизвестно. Коллега ранее использовал неразмеченный GLUE test при доменном отборе других моделей, поэтому этот источник нельзя характеризовать как полностью неизвестный проекту.

Весь набор — основная дополнительная метрика; вторую заранее определённую оценку считаем после исключения тестовых текстов, имеющих точное совпадение либо общий 8-грамм с допустимым обучающим пулом серии 07 (совпадение не обязательно означает общую исходную запись). Индексы и контрольный хэш фиксируются до предсказаний. Используем одинаковые сохранённые лучшие checkpoints каждой из 24 моделей, `max_length=64`, accuracy и macro F1; сравниваем по тем же seed с `long_random` и не переобучаем по результатам теста. Этот новый для нашей серии набор уменьшает переиспользование 872-предложенной GLUE validation, но три сидa, множество методов и отсутствие контроля pretraining всё равно ограничивают выводы.
